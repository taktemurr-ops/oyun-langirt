# Langırt (oyun-langirt)

Masa Oyunları merkez uygulamasındaki langırt (masa futbolu) oyunu. Gerçek masadaki gibi 8 çubuk: kaleci, defans, orta saha ve forvet. Parmağını sağa sola kaydırınca çubukların birlikte kayar; topun arkasındaki oyuncu hizalanınca dokunup şut çekersin.

- 33 dil; kampanya, günlük, zen, sonsuz ve zamana karşı modları
- Rakip, boşlukları hesaplayarak şut çeker; zorluk seviyeyle artar
- Güçlendirici: Süper şut (10 saniye daha sert şutlar)
- Testler: `flutter test`
